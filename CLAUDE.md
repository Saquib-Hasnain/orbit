## Project: Orbit

**Orbit** is a Linear-inspired project management app for team collaboration on tasks. See `prd.md` for requirements and `plan.md` for the milestone tracker and build plan.

### Core Features
- User onboarding & team creation
- Workspace with multiple boards
- Kanban layout with drag-drop
- Team & user management
- AI-powered task features (AI SDK)
- Subscription plans (Stripe: Lite & Pro)

### Tech Stack
- **Frontend:** Next.js 16 App Router, React 19, TypeScript (strict)
- **Database:** Supabase (local via Docker, hosted in production)
- **UI:** shadcn/ui components, Tailwind CSS v4, dark mode default
- **Payments:** Stripe (subscriptions)
- **Email:** Resend (welcome & invitation emails)
- **AI:** Vercel AI SDK with Claude models
- **Integrations:** MCP for third-party services

## Key Conventions

### Next.js 16
- **Breaking changes:** Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` — APIs, conventions, and file structure may differ from earlier versions. The AGENTS.md block is auto-generated by `next dev`; commit it with your changes to keep the working tree clean.
- **Layout props:** Use `LayoutProps<"/">` (Next.js 16 typed layouts) rather than manually typing `{ children: React.ReactNode }`.
- **API routes:** Use the `proxy.ts` pattern as specified in Next.js 16 docs.

### Database
- **Supabase local-first:** Develop against local Docker instance, use migrations for schema changes.
- **Row Level Security:** Enable RLS on all tables; use policies for team/user isolation.
- **Realtime:** Subscribe to table changes for live collaboration on boards.
- **Naming:** Use snake_case for database columns, camelCase in TypeScript.

### UI & Styling
- **Dark mode default:** Theme system should default to dark, with light mode toggle in user settings.
- **shadcn/ui:** Install components via CLI (`npx shadcn@latest add <component>`), customize in `components/ui/`.
- **Tailwind CSS v4:** Theme tokens in `app/globals.css` using `@theme inline`.
- **Responsive:** Mobile-first design; kanban should work on tablets.

### AI Features
- **AI SDK:** Use Vercel AI SDK with Claude models (see `/claude-api` skill for model IDs and best practices).
- **Features:** Task generation from natural language, label suggestions, description expansion.
- **Plan gates:** Free plan has no AI; Lite has basic AI; Pro has unlimited.

### Payments
- **Stripe:** Use Checkout for subscriptions, Customer Portal for management.
- **Plans:** Free (1 board, 5 members), Lite ($10/mo), Pro ($25/mo).
- **Webhooks:** Handle `checkout.session.completed`, `customer.subscription.updated/deleted`.

### Code Quality
- **TypeScript:** Strict mode; no `any` types without justification.
- **ESLint:** Flat config format (`eslint.config.mjs`) using `eslint-config-next/core-web-vitals` and `eslint-config-next/typescript`.
- **Error handling:** Wrap async operations in try-catch; return structured errors to client.
- **Security:** Validate all inputs with Zod; use parameterized queries; sanitize user content.

## Development Workflow

1. **Start local Supabase:** `npx supabase start` (first time: initializes Docker containers)
2. **Run dev server:** `npm run dev`
3. **Create migration:** Edit schema, then `npx supabase db diff -f <name>` to generate migration
4. **Install shadcn component:** `npx shadcn@latest add <component-name>`
5. **Test payments:** Use Stripe test mode with test cards (4242 4242 4242 4242)
